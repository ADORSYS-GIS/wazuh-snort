# wazuh-snort Documentation

The `wazuh-snort` repository contains resources for installing and configuring Snort, as well as integrating it with Wazuh to improve network security monitoring and threat detection. It provides a Helm chart, installation and configuration scripts for Linux, macOS, and Windows, and Snort rules.
